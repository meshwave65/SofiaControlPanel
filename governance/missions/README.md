# `governance/missions/` — missões de governança

Este diretório contém a documentação canônica de contexto das missões de governança numeradas `0001`–`0023`: blueprints, README de continuidade, progresso, quadros de tarefas, checkpoints, evidências e decisões.

A série de governança é diferente da série operacional `SCP-TASK-*` em `missions/`. A missão de governança pode conter muitas tarefas e muitos artefatos; esses arquivos não são novas missões independentes.

Para `0009` em diante, quando a pasta existe, o blueprint/README dentro desta árvore é a referência principal de continuidade. Os arquivos `MISSION_*` soltos na raiz são snapshots históricos preservados por compatibilidade e rastreabilidade. Não apagar, renomear em massa ou reclassificar esses snapshots sem atualizar os links dependentes.

A visão consolidada está em [`../../MISSIONS_INDEX.md`](../../MISSIONS_INDEX.md).
