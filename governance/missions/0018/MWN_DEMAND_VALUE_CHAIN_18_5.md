## Value-chain caveat

Project adoption can create utility, service revenue, or network workloads without necessarily creating demand for MWN. The direct token-demand path exists only when an approved economic rule requires or uses UMS/MWN, and the activity is measured in the ledger/market. A price/valuation thesis requires supply, conversion, market depth, actual activity and legal/operational readiness; none is guaranteed by the portfolio map.
