## Investor-safe synthesis

**MeshWave is an existing, partially built and evolving ecosystem.** The evidence inventory contains concrete software, a public information portal, an authenticated wallet frontend, controlled ledger/pilot records, CI-tested code and laboratory prototypes. The current evidence does **not** establish a fully integrated production network or exchange. MW-Ex is a nonfunctional visual preview; external listing, liquidity, token rights and full UMS↔MWN market operation remain open gates. The investment thesis should frame capital as potential professionalization, integration and acceleration, not guaranteed return.

## Remaining gates / evidence requests

1. Authenticated E2E validation of wallet/acquisition flow in a designated test environment; no live financial transaction unless separately authorized.
2. Current deployment/runtime provenance for the website and wallet frontend; CI build success alone is insufficient.
3. MW-Ex product, custody/signing, transaction, reconciliation, security, compliance and liquidity design/implementation before describing it as operational.
4. Independent verification and operational maturity of the blockchain beyond single-operator pilot.
5. Benchmarks for SWE and Condenser; method/measurement validation for MIA-D.
6. Approved scope, implementation and user/engagement evidence for Jardim do Éden and voluntary MeshWalker participation.
7. Human decisions on token identity/rights, supply, conversion, market access, compliance and communication gates.
