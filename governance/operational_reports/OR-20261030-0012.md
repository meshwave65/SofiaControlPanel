## Findings
1. Zenodo 17771555 is a note by the Multiflux author interpreting Camlin's iDNS work; it does not report an independent measurement of Multiflux subflows or N(t).
2. The original iDNS repository and v2.0.0 release were located and inspected.
3. The 2D solver uses `phi_prime=1/sigma`, RHS factor `1/phi_prime`, and physical-time increment `t += phi_prime*dt`; this pair does not satisfy the standard time-change chain rule.
4. The 3D Taylor–Green solver uses `dt=dt_base*phi` and an unscaled RK4 RHS, i.e. variable physical timestep rather than the same lifted-time formulation as the 2D solver.
5. The arXiv v2 paper defines (U(x,τ)=u(x,φ(τ))) and (t=φ(τ)), but its Theorem 3.1 equation and weak-form chain-rule step use the reciprocal factor. This is an apparent algebraic error requiring author clarification.
6. The iDNS README itself classifies Re=10^5, N=128³ and Re=10^8, N=256³ as DNS-Coarse (R<1), not fully resolved DNS. The Re=10^8 Kolmogorov case is 2D and does not test 3D global regularity.
7. A temporal sampling multiplier is not equivalent to a spatial subflow count; no direct N(t) measurement is presented.

## Limitations
No iDNS code or CSV was executed/reproduced. The assessment is static. The time-change diagnosis follows the published definitions and requires a corrected derivation or code from the original author to resolve.
