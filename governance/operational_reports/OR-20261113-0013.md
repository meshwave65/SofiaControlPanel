## Owner direction

Below each token indicator, display its current market/reference value and daily percentage movement side by side. Keep the token's full name in smaller type. Trend semantics: red down arrow for decline, blue bidirectional vertical arrow for stable, green up arrow for rise.

## Implementation

- Updated `src/pages/MwExOrderPreview.jsx` token strip for MWN, BTC and ETH.
- BTC and ETH read from the existing `/api/market-data` endpoint; the panel refreshes every 60 seconds and uses each asset's supplied `value`, `unit` and `changePercent`.
- MWN reads the existing enabled BRL reference from `mwc_sale_prices` (`price_per_mwc`, `updated_at`) using the existing Supabase client.
- Added trend glyphs and colors: down/red, stable/blue (↕), up/green.
- Kept full token names in smaller type below their symbols.
- Added responsive horizontal scrolling on narrow screens.

## Data integrity

- No hardcoded sample price or daily percentage was introduced.
- MWN's current source is an internal reference price, not a public market quote or executable price. That table does not provide a daily percentage series, so MWN's daily change is shown as unavailable rather than fabricated.
- If the market endpoint does not return a quote or daily change for BTC/ETH, the UI indicates that data is unavailable.
- No market-data backend, Supabase schema, database, ledger, wallet, order engine, RPC or financial rule was modified.
